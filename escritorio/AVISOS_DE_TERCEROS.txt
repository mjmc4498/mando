Presentazo para escritorio: avisos de software de terceros
==========================================================

Presentazo para escritorio incluye estas bibliotecas de código abierto, distribuidas
con la licencia MIT:

  • Electron (https://www.electronjs.org): la base de la app de escritorio.
    © Electron contributors y © 2013-2020 GitHub Inc. Electron incluye Chromium y
    otros componentes; sus licencias están en los archivos LICENSE y
    LICENSES.chromium.html que acompañan a la app.
  • Koffi 3 (https://koffi.dev): permite enviar teclas y movimientos del mouse al
    sistema. © Niels Martignène.
  • PeerJS 1.5.5 (ui/lib/peerjs.min.js): conexión WebRTC entre el celular y la
    computadora. © 2015 Michelle Bu y Eric Zhang. https://peerjs.com
  • QR Code Generator for JavaScript 2.0.4 (ui/lib/qrcode.mjs): genera el código QR.
    © 2009 Kazuhiko Arase. https://github.com/kazuhikoarase/qrcode-generator
